QUICK DEPLOYMENT GUIDE
================================================================================

STEP 1: Install Wrangler (one-time)
$ npm install -g wrangler

STEP 2: Authenticate with Cloudflare
$ wrangler login
(Opens browser for one-click auth)

STEP 3: Deploy to Cloudflare
$ wrangler pages deploy public/

STEP 4: Get Your Live URL
Look for output:
  ✓ Deployment complete!
  🌍 Deployment URL: https://marvel-details-[random].pages.dev

STEP 5: Configure GA4 (2 min)
- Get your GA4 Measurement ID
- Replace G-XXXXXXXXXX in all HTML files
- Redeploy

STEP 6: Submit to Search Engines (5 min)
- Google Search Console: Submit sitemap.xml
- Bing Webmaster: Verify site
- Monitor robots.txt accessibility

SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues:

Q: "Not authenticated" error when deploying
A: Run `wrangler login` first

Q: 404 errors on some pages
A: Check that all files exist in public/ directory
   Run: find public -type f | wc -l

Q: GA4 not tracking
A: Replace G-XXXXXXXXXX with real Measurement ID
   Redeploy after editing HTML files

Q: CSS not loading
A: Styles are inline in HTML files
   Check page source (view → source)
   All styles should be in <style> tag

Q: Images not showing
A: Site uses no image files in Phase 1
   All visuals are CSS-based or text descriptions
